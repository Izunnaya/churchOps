2Batch 2 — auth, Secretary, Treasurer history/revision, quarterly report, notifications
Everything here is built to the fixed standard set in turn 1: same warm-grey base, crest colors as accents only, IBM Plex Sans with tabular figures, ≥48px targets, and status shown as icon + label. Approvals and irreversible actions reuse the confirmation sheet from the Pastor's flow (1d).
Three-tap principle. Every important task should be completable in three taps or fewer where practical. In this batch that holds for: approve a leader account (dashboard → approvals → Approve), open a member's attendance timeline (search → member → profile), and find a past offering (history → filter → open). It genuinely cannot hold for three screens, each flagged in place below: Login (credentials require typing), Record revision and Return a report (both demand a written reason — that friction is deliberate, it protects the audit trail), and the Quarterly report (it is a writing task, not a tap task).
